# Flan Club 🍮

Le guide des meilleurs flans pâtissiers de France (on commence par le Pays Basque).

Site : https://maider-mi.github.io/Flan_club/

## Contenu

- `index.html` : la structure de la page
- `style.css` : les couleurs et la mise en page
- `script.js` : les flans, la recherche, le tri, la carte et la notation
- `images/` : les illustrations des flans

## Ajouter un flan à la main

Dans `script.js`, copier une ligne de la liste `flansLocaux` et changer les infos.
